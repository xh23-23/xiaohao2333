## 视觉规范

- 整页背景保留可见但克制的淡蓝紫磨砂透光感；企业详情使用最新淡背景版。
- 前景信息卡片使用白色、不透明底，文字与数据保持清晰。
- 顶部与底部左侧保留彩色青紫通约 Logo。
- 品牌色用于主要操作、选中状态和必要强调。
- 企业卡片紧凑，三个指标对齐，明确使用“关注”和“选择对比”。
- 企业详情保留“概览／资料／跟进”，清楚展示关注、加入对比和研究入口。
- “未提供”“未收录”“表内 0 条”是不同的数据状态，实现时必须保留其含义。

## 数据说明

企业详情示例按用户演示站展示内容核对：成都辛克普雷科技有限公司，成立日期 2019-01-14，2025 参保 29 人，专利首页记录 3 条，注册在园，招投标表内 0 条，融资记录未提供。来源为园区企业名录，采集日期未提供。以上为演示站内容核对，并非现实企业数据的独立审计。

AI 效果稿中的文字、Logo 和图形在代码实现时应使用真实文本与原始品牌资产重建。
